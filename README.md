# JARVIS Voice Assistant

JARVIS is a Python-based voice-controlled desktop assistant designed to make everyday tasks easier through natural voice commands.

It runs entirely through the console. You speak to JARVIS, and it listens, processes your request, and responds using voice.

## Features

- Wake word detection using `Jarvis` or `Hey Jarvis`
- Google Speech Recognition for voice input
- Windows SAPI5 text-to-speech using `pyttsx3`
- Gemini AI for general questions and conversations
- Date and time information
- Wikipedia information lookup
- Personal notes
- Joke generation
- Rock, Paper, Scissors
- Open Google
- Open YouTube
- Open YouTube Music
- Open Notepad
- Open Calculator
- Recycle Bin control
- Conversation logging
- Modular Python architecture

## Tech Stack

- Python
- Google Gemini API
- SpeechRecognition
- pyttsx3
- Windows SAPI5
- Wikipedia
- Web browser automation
