#**JARVIS Voice Assistant**#

JARVIS is a voice-controlled desktop assistant built with Python.

This is console based AI assistant for your day to day work,It is console based assistant. 

*Features*

- Wake word detection using "Jarvis" or "Hey Jarvis"
- Google speech recognition
- Windows SAPI5 text-to-speech through pyttsx3
- Gemini AI responses
- Date and time
- Wikipedia information
- Notes
- Jokes
- Rock, paper, scissors
- Opening Google, YouTube and YouTube Music
- Opening Notepad and Calculator
- Recycle Bin control
- Conversation logging

*Setup*

Install the dependencies:
    => pip install -r requirements.txt

Adding API Keys:
    =>1. Get API from "https://ai.google.dev/api"
      2. Copy the Gemini API key. 
      3. Add the API key the config.py file.

Then start JARVIS:

click on start.bat

Say "Hey Jarvis" or "Jarvis" to activate it.
